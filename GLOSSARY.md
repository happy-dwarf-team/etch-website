# Etch website

The website of Etch at `etch.happydwarf.dev`: a landing page with a demo loop, the preview's
features, the live game, install and the roadmap. Terms about Etch itself are in
[`etch`'s GLOSSARY.md](https://github.com/happy-dwarf-team/etch/blob/main/GLOSSARY.md); terms
shared by the team's sites are in
[`happydwarf-website`'s GLOSSARY.md](https://github.com/happy-dwarf-team/happydwarf-website/blob/main/GLOSSARY.md).

## The site

**Launch**:
The moment the site's final domain serves it: the Pages custom domain is set, the `etch` record
exists, and the HTTPS certificate is issued and checked.
_Avoid_: release (release-please's word), go-live

**Site name**:
`Etch`, the name after `|` in page titles and in `og:site_name`.
_Avoid_: brand name

**Install band**:
The one-line section with the install command, its Copy button and the first step.
_Avoid_: install section, quick start

**Feature tour**:
The numbered feature rows, each a short text beside its feature's loop: six of the offline
preview, then three of the live game.
_Avoid_: gallery, feature grid

**Roadmap**:
The vertical timeline M0 → 1.0.0 from `etch`'s v1 specification, then 2.0.0 from its v2
specification.
_Avoid_: timeline (for the content), plan

## Media

**Demo loop**:
The hero's short silent video of Etch at work, a trailer of three feature loops, with a poster, a
Pause/Play button and a text description.
_Avoid_: hero video, GIF

**Feature loop**:
One feature's short silent video in the tour, with its poster, Pause/Play button and text
description, as the demo loop's.
_Avoid_: screenshot, GIF

**Poster**:
The loop's first frame as a still image; shown before playback, under reduced motion and with
Save-Data.
_Avoid_: thumbnail, cover

**Loop viewer**:
The dialog that shows a loop large, with the video's controls and its text description, opened
by Enlarge or a click on the loop.
_Avoid_: lightbox, modal, zoom view

**Unavailable state**:
How a loop renders when there is no media manifest yet or its load failed: the reserved box
with the text description.
_Avoid_: placeholder, empty state

**Media manifest**:
`src/data/media.json`, generated by `pnpm media publish` in `etch`; the only place the site
learns media bucket keys from.
_Avoid_: media index, media list

**Clip**:
One named loop (`hero`, `preview`, `views`, `data`, `zoom`, `outline`, `problems`, `reload`,
`pick`, `snapshot`) that the media script makes; its id appears in the bucket key, the file name
and the manifest. Until 2.0.0's media refresh the ids named scenes, most of them stills.
_Avoid_: scene, shot

**Media refresh**:
Capturing Etch's media for one Etch release and publishing them: loops to the media bucket;
posters and the media manifest to this site.
_Avoid_: media update, re-record

**Demo mod**:
The workspace of Etch's media: our own files, drawn with the game's art; since 2.0.0 the
clips edit its throwaway override of the base game's `provinceview.gui`.
_Avoid_: sample mod, test mod, fixture

**Takedown**:
Deliberate removal of published media from the bucket and the site; the only reason objects are
ever deleted.
_Avoid_: cleanup, prune

## Paradox

**Our reading**:
The interpretation of section 6 of the Paradox User Agreement that own-site hosting of free Etch
media is covered; the basis the site launches on.
_Avoid_: permission, licence

**Trigger**:
One of four events (logo or key art wanted, monetization, Paradox contacts us, sections 5–6
change against our reading) that requires asking Paradox before acting.
_Avoid_: red flag

**Disclaimer**:
The footer block on every page: the non-affiliation line, the trademark line and, because the
site shows EU4 art, the game-art line.
_Avoid_: legal notice
